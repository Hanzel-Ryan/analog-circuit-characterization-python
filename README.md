# Analog Circuit Characterization with Python, LTspice & Experimental Validation

Experimental characterization of four analog circuits using physical laboratory measurements,
LTspice simulation, theoretical circuit analysis, and Python-based data processing.

Circuits analyzed:
- TIP41C voltage-divider common-emitter BJT amplifier
- IRF630 common-source MOSFET amplifier
- LM358P active low-pass filter
- LM358P active high-pass filter

Python was used to process frequency-sweep measurements, calculate voltage gain in dB,
determine -3 dB cutoff frequencies and bandwidth, quantify measured-vs-simulated deviation,
and generate frequency-response plots.
